JournalMate 利用規約

制定日・最終更新日: 2026年9月27日

この利用規約（以下「本規約」）は、[運営者名]（以下「運営者」）が提供する iOS アプリ「JournalMate」および本アプリに付随して提供する中継サーバ等のサービス（以下あわせて「本サービス」）の利用条件を定めるものです。本サービスをご利用になる方（以下「ユーザー」）は、本規約に同意のうえ本サービスをご利用ください。

要点
  • アカウント登録はありません。本アプリをダウンロードして利用した時点で、本規約に同意したものとみなします。
  • 記録は端末内にだけ保存されます。アプリを削除すると記録はすべて消え、運営者も復元できません。設定の「バックアップを書き出す」で、ご自身で保存してください。
  • AI の返答やジャーナルの書き起こしは誤りを含むことがあります。医療・法律・金融などの専門的な助言ではありません。
  • 有料プラン（Pro / Max）は App Store の自動更新サブスクリプションです。解約・返金は Apple の手続きによります。

第1条（適用）

  1. 本規約は、ユーザーと運営者との間の本サービスの利用に関わる一切の関係に適用されます。
  2. 運営者が本アプリ内または運営者のウェブサイトに掲載する、本サービスの利用に関するルールや説明（以下「個別規定」）は、本規約の一部を構成します。
  3. 本規約と個別規定の内容が異なる場合は、個別規定に特段の定めがない限り、個別規定が優先して適用されます。

第2条（定義）

本規約において、次の用語は以下の意味で使用します。

  1. 「AI 機能」とは、AI チャット、ジャーナルの書き起こし、PARA の自動推定、受信箱の一括分類、週次・月次の振り返り、knowledge（教訓）の生成など、Anthropic, PBC が提供する Claude API を利用する本アプリの機能をいいます。
  2. 「中継サーバ」とは、AI 機能の呼び出しを Anthropic に中継するために運営者が運用するサーバをいいます。
  3. 「ユーザーコンテンツ」とは、ユーザーが本アプリで作成・入力・取り込みした文章、ジャーナル、メモ、フォルダ構造、画像その他の情報、および AI 機能によってユーザーのために生成された文章をいいます。
  4. 「有料プラン」とは、Pro および Max その他運営者が定める有償の利用プランをいいます。

第3条（利用条件）

  1. 本サービスの利用にアカウント登録は不要です。ユーザーは、本アプリをダウンロードし利用を開始した時点で本規約に同意したものとみなされます。
  2. 未成年のユーザーは、親権者など法定代理人の同意を得たうえで本サービスを利用してください。13 歳未満の方は本サービスを利用できません。
  3. 本サービスの利用に必要な端末、通信環境および通信費用は、ユーザーの負担とします。

第4条（有料プランと支払い）

  1. 有料プランは、Apple Inc. が提供する App Store のアプリ内課金による自動更新サブスクリプションとして提供します。料金、課金期間その他の条件は、購入画面に表示するとおりとします。
  2. 代金の支払い、自動更新、解約および返金は、Apple の定める規約と手続きに従います。自動更新は、各期間の終了の 24 時間前までに App Store のアカウント設定で停止しない限り、自動的に行われます。運営者は代金の返金を直接行うことはできません。
  3. 本アプリ内の無料トライアルは、支払い情報の登録なしに所定の期間 AI 機能を利用できるものです。終了後に自動で課金されることはありません。無料トライアルは 1 台の端末につき 1 回に限り利用できます。
  4. 有料プランに加入していないユーザーは、運営者が定める回数の範囲で一部の AI 機能を無料で利用できます（以下「無料枠」）。無料枠は端末ごとに管理し、本アプリの再インストールによって回復しません。
  5. 有料プランおよび無料枠のいずれにおいても、AI 機能には運営者が定める 1 日・1 か月あたりの利用量の上限があります。上限に達した場合、次の期間まで AI 機能を利用できないことがあります。
  6. 運営者は、有料プランの料金、内容、利用量の上限および無料枠を変更することがあります。料金の変更は、Apple の定める手続きに従って行います。

第5条（AI 機能）

  1. AI 機能を利用するには、本アプリ内で AI へのデータ送信に同意していただく必要があります。同意はいつでも本アプリの設定から取り消すことができます。同意がない間も、AI 機能以外の機能は利用できます。
  2. AI 機能を利用すると、その処理に必要なユーザーコンテンツが中継サーバを経由して、またはユーザー自身の API キーを使う場合は直接、Anthropic に送信されます。送信される情報とその取り扱いは、プライバシーポリシーに定めるとおりです。
  3. AI 機能による返答、書き起こし、分類、要約その他の出力（以下「AI 出力」）は、自動的に生成されるものであり、不正確、不完全または不適切な内容を含むことがあります。運営者は AI 出力の正確性、完全性、有用性を保証しません。
  4. AI 出力は、医療、心理、法律、税務、金融その他の専門的な助言に代わるものではありません。心身の健康や重要な判断に関わる事柄については、ユーザーご自身の判断で専門家にご相談ください。
  5. ユーザーが自らの Claude API キーを本アプリに入力して AI 機能を利用する場合、その利用には Anthropic との間の契約が適用され、利用料金はユーザーが Anthropic に対して負担します。
  6. ユーザーは、AI 機能の利用にあたり、Anthropic の定める利用ポリシーに従うものとします。

第6条（ユーザーコンテンツとデータの管理）

  1. ユーザーコンテンツに関する権利は、ユーザーまたは正当な権利者に帰属します。運営者は、AI 機能の処理のために中継する場合を除き、ユーザーコンテンツを取得・保存・利用しません。
  2. ユーザーは、自ら権利を有するか、権利者から必要な許諾を得た情報に限り、本アプリに入力または取り込むものとします。
  3. ユーザーコンテンツは、ユーザーの端末内にのみ保存されます。運営者のサーバには保存されないため、本アプリの削除、端末の故障・紛失・初期化、OS の不具合その他の理由で失われたユーザーコンテンツを、運営者が復元することはできません。
  4. 本アプリは、ユーザーコンテンツを 1 つの .zip ファイルに書き出す機能（設定 > バックアップを書き出す）と、書き出したファイルから本アプリに戻す機能（設定 > バックアップから復元）を提供します。書き出したファイルの保存・管理はユーザーご自身の責任で行ってください。書き出したファイルは暗号化されないため、第三者と共有する場所に保存する際はご注意ください。
  5. バックアップから復元すると、本アプリ内のフォルダ、ジャーナル、メモおよび会話の記録は、バックアップの内容に置き換わります。バックアップの作成後に記録した内容は失われます。
  6. ジャーナルにしなかったチャットの記録や削除したメモは、本アプリの仕様に従い、一定期間の経過後に自動的に消去されます。
