よくある質問 / FAQ

無料で使えますか？
ジャーナルの記録・カレンダー・ディレクトリ・Markdown の書き出しは無料です。AI でのジャーナル抽出は月 20 回まで無料で、AI チャット・振り返り・受信箱の一括分類・教訓の生成は Pro（サブスクリプション）の機能です。
解約するには？
iPhone の「設定」→ 自分の名前 →「サブスクリプション」→ JournalMate から解約できます。期間終了の 24 時間前までに解約すると、次回の請求は発生しません。
機種変更したとき、購入を引き継げますか？
同じ Apple ID でサインインし、アプリの「設定」→「購入を復元」を押してください。
データはどこに保存されますか？
端末内だけです。AI の機能を使うときだけ、同意のうえで文章が Anthropic の Claude API に送られます。詳しくは プライバシーポリシー をご覧ください。
Obsidian などに移せますか？
「設定」→「バックアップを書き出す」で、フォルダ階層ごと .md ファイル（YAML frontmatter 付き）の zip になります。アプリを入れ直したあとは「バックアップから復元」でその zip を選ぶと元に戻せます。
